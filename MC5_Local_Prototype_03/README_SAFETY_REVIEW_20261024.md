# जमीन निदान पोर्टल V2 — कलम ५ | AI Acceptance Safety Review
**स्थिती:** विकासकाच्या स्थानिक चाचणीसाठी अद्ययावत Prototype 03. प्रत्यक्ष Generative AI API चाचणी झालेली नाही. Production-ready किंवा न्यायालयात वापरण्यास मंजूर नाही.

## या सुधारित पॅकेजमध्ये झालेले काम
- मूळ ४० चाचण्यांना **११ नवीन चाचण्यांची** जोड: पाच कृत्रिम अर्थ-विरोधी AI प्रतिसादांना नकार, पाच योग्य मजकूर उदाहरणांवर चुकीचा नकार नाही याची पडताळणी, आणि API पूर्वतयारी तपासणी.
- `app/semantic_guard.py` — **मर्यादित** स्पष्ट अर्थ-विरोध तपासणी (पूर्वअस्तित्व, गाव रस्त्याशी अपुष्ट जोड, स्थिती ३ मध्ये चालू अडथळा, उपलब्ध पुरावे नाकारणे, झालेले प्रयत्न नाकारणे).
- `app/controlled_ai.py` — विद्यमान स्रोत/अंक तपासणीनंतर वरची अतिरिक्त अर्थ-विरोध तपासणी जोडली. मंजूर १३ विषय, क्रमांक, शब्दांकन व अंतिम मागण्या बदललेल्या नाहीत.
- `scripts/check_live_ai_readiness.py` — API configuration आहे का हे **संपर्क न करता** तपासणारा सुरक्षित कार्यक्रम. API Key किंवा मूल्ये कधीही छापत नाही.
- चार अंगभूत काल्पनिक प्रकरणांसाठी Offline Fake Provider पुन्हा चालवून मानवी पुनरावलोकन आवश्यक हीच स्थिती राखली.

## प्रत्यक्ष चाचणी निकाल
- `python -m pytest tests -q` → **51 passed** (या पॅकेजच्या निर्माणावेळी).
- चार Synthetic Offline Comparison Runs → `STRUCTURAL_OK_HUMAN_REVIEW_PENDING`.
- API readiness → `NOT_READY` (Provider, Model, API Key, SDK, आवश्यक स्पष्ट अनुमती अनुपलब्ध).
- **बाह्य API कॉल 0.** प्रत्यक्ष मॉडेलची मराठी गुणवत्ता अजून अज्ञात.

## विकासकाने प्रत्यक्ष Live Test साठी काय करावे?
1. प्रथम `python scripts/check_live_ai_readiness.py` चालवा. ही चाचणी बाह्य API वापरत नाही.
2. अधिकृत संस्थात्मक API credentials सुरक्षित Secret Manager / environment मध्येच द्या; Chat, Source Code, ZIP, Git मध्ये देऊ नका.
3. केवळ बनावट चार प्रकरणांसाठी `README_LIVE_AI_ACCEPTANCE.md` मधील स्वतंत्र `--live-synthetic-only` अनुमत चाचणी चालवा.
4. चारही *मूळ विरुद्ध AI प्रस्ताव* तुलना दस्तऐवज, प्रत्येक परिच्छेदातील तथ्ये आणि मराठी अर्जभाषा स्वतंत्रपणे तपासा. `HUMAN_SCORECARD.csv` पूर्ण करा.
5. एकही तथ्यात्मक किंवा कायदेशीर विसंगती आढळल्यास अर्ज **नकार/मानवी दुरुस्ती** स्थितीत ठेवा. वास्तविक प्रकरणे अपलोड किंवा पाठवू नका.

## महत्त्वाच्या मर्यादा
ही तपासणी **शब्दसंकेतांवर आधारित आहे; अर्थाचे सर्व प्रकार समजणारी पडताळणी नाही.** सूक्ष्म उलटार्थ, गाळलेली घटना, मार्गाचा चुकीचा संदर्भ, चुकीचा कायदेशीर निष्कर्ष आणि गोपनीय मजकूर हमखास पकडते असा दावा नाही. स्रोत-नकाशा आणि मानवी परीक्षण आवश्यक.

प्रत्यक्ष वापरापूर्वी आणखी करणे आवश्यक: मंजूर प्रश्नावलीची प्रत्यक्ष UAT, OCR व 7/12 नावांची पडताळणी, OTP, सुरक्षित डेटा साठवण व प्रत्यक्ष deletion, कायदेशीर मागणी २ ची पडताळणी, Word अंतिम नमुना स्वीकारणे, सुरक्षा/गोपनीयता व Live AI गुणवत्ता परीक्षण.
