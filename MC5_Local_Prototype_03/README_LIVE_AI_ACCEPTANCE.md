# कलम ५ — प्रत्यक्ष AI चाचणी आणि मानवी स्वीकृती

**वास्तव स्थिती:** यामधील बाह्य AI सेवा या पॅकेजच्या निर्मितीवेळी चालवलेली नाही. कोणतीही API Key किंवा वास्तविक 7/12 माहिती पॅकेजमध्ये नाही.

हे Prototype 03 वरील **चाचणी-अ‍ॅडऑन** आहे. कोणत्याही मंजूर Master/प्रश्नावलीचे शब्दांकन बदलत नाही.

## १. सुरक्षित ऑफलाइन परीक्षण — शून्य नेटवर्क

```bash
python -m pip install -r requirements.txt -r requirements-dev.txt
python -m pytest tests -q
python scripts/live_ai_acceptance_review.py --offline-fake --export-review-artifacts
```

`qa/live_acceptance/offline_fake/` मध्ये ४ काल्पनिक Word अर्ज, ४ *मूळ विरुद्ध AI* तुलनात्मक Word फाइल्स, `HUMAN_SCORECARD.csv` आणि `SUMMARY.json` तयार होतील. Fake Provider मूळ मजकूर तसाच परत करतो; AI गुणवत्ता तपासली असे समजू नये.

## २. वास्तविक बाह्य AI चाचणी — फक्त विकासकाच्या अधिकृत सुरक्षित वातावरणात

```bash
python -m pip install -r requirements-ai.txt
export MC5_AI_PROVIDER=openai
export MC5_AI_ALLOW_EXTERNAL=true
export MC5_AI_MODEL='<organisation-approved-model-id>'
# OPENAI_API_KEY सुरक्षित secret manager/environment मध्ये सेट करा, चॅट/ZIP मध्ये नाही.
export MC5_LIVE_SYNTHETIC_TEST_APPROVED=YES
python scripts/live_ai_acceptance_review.py --live-synthetic-only
```

वरील पद्धतीत **फक्त चार अंगभूत काल्पनिक प्रकरणांवर** API कॉल होतात. AI मजकूर कायमस्वरूपी सेव्ह होत नाही; केवळ सुरक्षित निकाल मिळतो. संस्थेची स्वतंत्र API-डेटा/खर्च मंजुरी आवश्यक.

### Live AI मजकुराचे स्थानिक पुनरावलोकन हवे असल्यास

```bash
export MC5_LIVE_REVIEW_EXPORT_APPROVED=YES
python scripts/live_ai_acceptance_review.py --live-synthetic-only --export-review-artifacts
```

यामध्ये **केवळ काल्पनिक माहितीचे** स्थानिक Word अर्ज आणि बाजूबाजूची तुलना जतन होते. त्या फाइल्स डिफॉल्टने खाजगी परवानग्यांत तयार होतात. हा निर्यात पर्याय स्पष्ट मंजुरीशिवाय कार्यरत होत नाही. प्रत्यक्ष जमीनधारकांची कागदपत्रे किंवा नाव-पत्ता यात पाठवू नका.

## ३. मानवी QA — प्रत्येक नमुन्याला स्वतंत्र गुणवत्ता/तथ्य मंजुरी

तुलनात्मक Word मध्ये प्रत्येक परिच्छेदाचा मूळ व AI मजकूर समोरासमोर आहे. प्रत्येकासाठी तथ्यस्रोत व मराठी न्यायालयीन भाषा तपासावी. `HUMAN_SCORECARD.csv` मध्ये प्रत्येक चार परिस्थितींसाठी ९ निकष आणि `human_result` / `reviewer_notes` वापरावे. नोंद पूर्ण व स्वाक्षरीकृत होईपर्यंत QA `NOT_REVIEWED` राहते.

**महत्त्वाचे:** स्वयंचलित चाचणी धोकादायक *अंक/काही शब्द* शोधू शकते, पण अंक नसलेली काल्पनिक घटना, अभिप्रेत मालकी, चुकीचा अर्थ किंवा तथ्यांमधील सूक्ष्म विसंगती हमखास शोधू शकत नाही. म्हणून सर्व परिच्छेदांचे मानवी परीक्षण बंधनकारक.

## ४. अजून उत्पादनासाठी न पूर्ण झालेले

प्रत्यक्ष Live AI गुणवत्ता चाचणी, अंतिम Word साच्याची वापरकर्ता-मंजुरी, OCR आणि 7/12 पडताळणी, OTP, सुरक्षित खाती, डेटाची ३० दिवसांनंतर प्रत्यक्ष विल्हेवाट, कायदेशीर मागणी #2 पडताळणी, सुरक्षा आणि गोपनीयता चाचणी.

**ही चाचणी न्यायालयीन ग्राह्यता किंवा वापरासाठी अंतिम मंजुरी नाही.**
