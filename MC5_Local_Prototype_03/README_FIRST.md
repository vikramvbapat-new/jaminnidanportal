# जमीन निदान पोर्टल V2 — कलम ५ | स्थानिक Prototype 02

**स्थिती: कार्यरत स्थानिक संदर्भ-नमुना; न्यायालयीन अर्ज तयार करून दाखल करण्यासाठी अंतिम प्रणाली नाही.**

या आवृत्तीत Prototype 01 चे सात टप्पे, मूलभूत मराठी Word मसुदा, २४ ऑक्टोबर २०२६ चे मंजूर तीन निर्णय आणि Master Paragraph क्रमांक कायम ठेवले आहेत. नवीन भाग म्हणजे **Controlled AI Integration Boundary** — बाह्य AI सेवेकडून फक्त निवडक परिच्छेदांची भाषा सुधारून घेणे, संरचना/तथ्य/स्रोताच्या नियमांद्वारे तपासणे, सर्व परिच्छेदांची मानवी पुष्टी घेणे आणि त्यानंतरच चाचणी Word तयार करणे.

## डिफॉल्टने सुरक्षित स्थानिक मोड चालवा

1. ZIP उघडा. Python 3.11 किंवा नवीन आवृत्ती असावी.
2. `python -m pip install -r requirements.txt`
3. Windows: `START_WINDOWS.bat`; Linux/Mac: `./START_LOCAL.sh`.
4. ब्राउझरमध्ये **http://127.0.0.1:8765** उघडा. `127.0.0.1` शिवाय इतर host वर उघडू नका.
5. **फक्त काल्पनिक माहिती** भरून नियमाधारित पूर्वावलोकन आणि `REVIEW_ONLY` Word वापरून पाहा.

**AI डिफॉल्टने बंद** आहे. AI बटण उपलब्ध नसले तरी स्थानिक नियमाधारित मसुदा व Word चालतात.

## ऐच्छिक बाह्य AI जोडणी — विकासकासाठी

विकासकाने स्थानिक चाचणीसाठी खालील गोष्टी स्पष्टपणे दिल्यानंतरच AI बटण कार्यान्वित होते:

```bash
python -m pip install -r requirements-ai.txt
export MC5_AI_PROVIDER=openai
export MC5_AI_ALLOW_EXTERNAL=true
export MC5_AI_MODEL='YOUR_APPROVED_SUPPORTED_MODEL'
export OPENAI_API_KEY='YOUR_SECRET_KEY'
./START_LOCAL.sh
```

Windows PowerShell मध्ये `export` ऐवजी `$env:MC5_AI_PROVIDER="openai"` इ. वापरा. `.env` फाइल या पॅकेजमध्ये ठेवलेली नाही; API Key कधीही Source Code, ZIP किंवा Screenshot मध्ये देऊ नका. वास्तविक API कॉल चालवण्यासाठी मॉडेल आणि संस्थेच्या डेटा-हाताळणी अटींची स्वतंत्र मंजुरी आवश्यक आहे. **या पॅकेजवर प्रत्यक्ष AI API कॉल केलेला नाही**; चाचण्या Fake Provider वापरून केलेल्या आहेत.

UI मधील AI बटणासाठी **प्रत्येक विनंतीला वापरकर्त्याची स्वतंत्र संमती** लागते. API ला फक्त निवडक पुष्टी झालेली तथ्ये पाठवण्याचा प्रयत्न आहे; पक्षकारांच्या नाव-पत्त्याच्या स्वतंत्र फील्ड्स पाठवले जात नाहीत. मुक्त मजकुरातील सर्व संवेदनशील माहिती ओळखण्याची हमी नाही. गाव/गट/रस्त्याचे तपशील स्वतःही खाजगी असू शकतात; त्यामुळे संस्थेची गोपनीयता आणि कायदेशीर तपासणी होईपर्यंत वास्तविक प्रकरणे वापरू नका.

## AI मसुद्याचे संरक्षक नियम

- AI फक्त **परिच्छेद २, ३, ४, ७–११** यांपैकी अर्जात लागू असलेल्या परिच्छेदांची भाषा सुधारू शकतो. परिच्छेद **१, ५, ६, १२, १३** आणि त्यांचे मंजूर विषय/क्रमांक प्रणाली निश्चित ठेवते.
- **मागण्या क्रमांक १–४, जमिनींचा पाच स्तंभांचा तक्ता, जोडपत्रांची यादी आणि कालमर्यादेचा निर्णय** AI कडून येत नाहीत; ते प्रणालीच्या मंजूर नियमांतून तयार होतात.
- AI उत्तरामध्ये दुसऱ्या परिच्छेदाचा पुरावा, दहाव्या परिच्छेदातील पुरावा 'जोडला आहे' असे अपुष्ट विधान, नवी संख्यात्मक माहिती, अपुष्ट आर्थिक नुकसान, कलम १४३ ची गल्लत, तांत्रिक खूणा/स्रोतांबाहेरील शब्दप्रयोग तपासले जातात. यामुळे **सर्व भाषिक किंवा तथ्यात्मक चुका सापडतील याची हमी नाही**.
- प्रत्येक परिच्छेदाखाली त्याचा स्रोत Field ID दाखवला जातो. **सर्व परिच्छेद स्वतंत्रपणे तपासलेले** असणे आणि अंतिम संमती आवश्यक आहे.
- मसुदा अथवा मूळ माहिती बदलल्यास मागील मंजुरी-टोकन अवैध. टोकन १५ मिनिटांत कालबाह्य. सर्व्हर पुनः सुरू झाल्यावर जुने टोकन निरुपयोगी.
- सहा महिन्यांच्या मुदतीचा प्रश्न आल्यास फक्त कायदेशीर पुनरावलोकनासाठी Word. **कोणत्याही परिस्थितीत हा नमुना Filing-ready प्रमाणित करत नाही.**

## विकासक चाचण्या

```bash
python -m pip install -r requirements-dev.txt
python -m pytest tests -q
node --check app/static/app.js   # Node.js असल्यास
```

या आवृत्तीत **२९ स्वयंचलित चाचण्या यशस्वी**, Fake Provider सह AI preview → per-paragraph review → Word flow याची चाचणी आणि दोन पानांचा Word QA नमुना प्रत्यक्ष Render करून पडताळणी झाली आहे. प्रत्यक्ष AI API response, OCR, OTP, सुरक्षा परीक्षण किंवा न्यायालयीन भाषेची अंतिम मानवी मंजुरी अद्याप नाही.

## वास्तु / API

- `app/engine.py` — मंजूर कायदे-नियमांचे संदर्भ-आधारित deterministic drafting व Word.
- `app/controlled_ai.py` — AI कडे पाठवायचे मर्यादित तथ्य, Responses API optional adapter, structured output, guards, HMAC review token.
- `app/server.py` — `/api/preview`, `/api/docx`, `/api/ai-preview`, `/api/ai-docx`, `/api/status`.
- `app/static/` — मोबाइल प्रश्नावली, स्वतंत्र AI consent आणि परिच्छेदनिहाय approval.
- `source_baseline/` — मूळ मंजूर Contract व S7 नियम, संदर्भ दस्तऐवज.
- `tests/` — काल्पनिक fixtures आणि regression/adversarial चाचण्या.
- `qa/` — Fake Provider चा Word QA नमुना व मोबाइल UI ची स्थिर मांडणी (ब्राउझर-API प्रत्यक्ष चाचणी म्हणून समजू नये).

## उत्पादन-प्रणालीसाठी बाकी

OCR ७/१२, OTP, auth/access controls, डेटाबेस/३०-दिवसांची प्रत्यक्ष डेटा-विल्हेवाट, HTTPS, व्यवहार नोंदी व घटना-विवरण, वास्तविक AI response परीक्षण, मराठी कायदेशीर भाषा मंजुरी, मागणी क्रमांक २ चा कायदेशीर आधार, अंतिम Word Layout/पक्षकार सत्यापन, सुरक्षा/गोपनीयता तपासणी आणि कलम १४३ स्वतंत्र मॉड्यूल. हा प्रोटोटाइप इंटरनेटवर सार्वजनिक उघडू नका.
